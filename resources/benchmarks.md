# Benchmark and Dataset Inventory

OCR benchmarks differ in input unit, output contract, metric, semantic load, and deployment assumption. This inventory extends the front-page benchmark table.

**Last source audit and search cutoff:** 2026-08-08. Inclusion requires a primary paper, official benchmark or project page, official repository, or official dataset card that defines the data or evaluation task. Reported scales and metrics follow those sources. The inventory distinguishes faithful transcription and source-grounded structural reconstruction from document understanding tasks whose labels add semantic interpretation.

## How to Read This Inventory

| Field | Meaning |
|:---:|:---|
| Date | arXiv `YYYY.MM` month when an arXiv version exists; otherwise the available public release, dataset, or challenge date. |
| Type | Benchmark, training corpus, challenge, or evaluation suite. |
| Input | Word crop, line image, scene image, document page, table crop, formula crop, PDF page, multi-page document, or QA pair. |
| Target / Metric | Typical target representation and common metrics. |
| Notes | Why the dataset matters for OCR or document parsing. |
| Links | Primary paper and official project, repository, benchmark, or dataset locations. |
